# Практическая работа №1.1 - Установка TypeScript

## Описание проекта
Проект демонстрирует базовые навыки работы с TypeScript: инициализацию проекта, настройку `tsconfig.json`, работу с типами, функциями и модулями. Включает мини-проект «Библиотека» для управления списком книг.

## Структура проекта
```text
ts-practice-1/
├── src/
│   ├── index.ts      # Основной файл с демонстрацией типов и функций
│   └── library.ts    # Модуль для работы с книгами
├── dist/             # Скомпилированные JS-файлы (генерируется автоматически)
├── node_modules/     # Зависимости
├── package.json      # Конфигурация npm
├── tsconfig.json     # Конфигурация компилятора TypeScript
└── README.md         # Этот файл
